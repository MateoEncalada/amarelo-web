# Sitio web Amarelo

Catálogo estático (HTML + CSS + JavaScript, sin dependencias). Pedidos solo por WhatsApp.

## Cómo verlo
- Opción 1: doble clic en `index.html`.
- Opción 2 (recomendada): en esta carpeta ejecutar `python3 -m http.server 8000` y abrir http://localhost:8000

## Qué editar
- `js/products.js`: productos, precios, colores, medidas, fotos.
- `js/whatsapp-order.js`: número de WhatsApp (`AMARELO_WHATSAPP_NUMBER`) y mensaje del pedido.
- `css/styles.css`: colores y diseño.
